東津御苑｜公開訂房查詢整合版

上線方式
1. 解壓縮本檔，將 index.html、assets/、booking/ 與所有 JPG 照片上傳至原官網同一目錄，覆蓋原 index.html。
2. 使用 GitHub Pages 時，將上述內容放在目前 Pages 的發布目錄；不要只上傳 ZIP 或外層資料夾。
3. 官網首頁導覽、主視覺、各客房與浮動按鈕皆已更新。
4. 原 /booking/ 路徑改由 booking/index.html 提供公開查詢，不需要 PHP 或登入。
5. 上傳後重新整理瀏覽器；若有舊 booking/index.php 或伺服器優先規則，請由管理者移除舊版路由干擾。

查詢內容
・入住／退房日期、成人、兒童與各兒童年齡、客房數。
・日期檢查、晚數摘要、台灣當地日期。
・送出後在新分頁開啟東津御苑 Booking.com 頁面，攜帶查詢條件。
・房號按鈕帶入房型參考與標準成人數，不宣稱指定房號可訂。
・不蒐集旅客姓名、電話或信用卡，不建立本地訂單。

實際串接範圍
這是官網整合的 Booking.com 查詢連結版，不是 API 庫存同步版。
本頁不顯示虛構房況或自動判定滿房，並不會在官網內讀取 Booking.com 空房數。
目前未取得平台房型 ID、授權 API 或 Channel Manager，因此未將 101～204 房號與平台房型建立自動庫存對應。
Booking.com 可能因訪客地區、驗證或平台改版要求重新確認日期、人數與兒童年齡；請於平台確認所有條件後再預訂。
民宿官網的房價與兒童政策是原附件介紹，Booking.com 的售價與政策以平台當次畫面為準。
如果要官網內顯示即時可訂房並直接下單，下一步需選用支援 Booking.com 的 Channel Manager／訂房引擎並授權，再逐項核對九間房與平台房型／庫存配置。
請勿把 Booking.com 帳密或 API 金鑰放入公開網頁。
